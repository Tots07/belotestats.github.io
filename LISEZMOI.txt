BELOTE STATS - version à héberger

Fichiers : index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, icon-maskable-512.png
Gardez-les tous dans le même dossier.

1) Héberger le dossier
   - Netlify Drop : ouvrez app.netlify.com/drop et glissez-y le dossier décompressé.
   - ou GitHub Pages : mettez les fichiers dans un dépôt et activez Pages.
   L'adresse doit commencer par https://

2) Installer sur Android
   Ouvrez l'adresse dans Chrome, puis menu (3 points) > "Installer l'application".
   Une icône Belote Stats apparaît sur l'écran d'accueil.

3) Option APK
   Sur pwabuilder.com, collez l'adresse de votre application puis "Package for stores" > Android.

Ouvrez l'application une première fois avec internet : elle se met ensuite en cache pour fonctionner hors ligne.
Les données restent dans le navigateur de chaque appareil (utilisez Exporter pour les sauvegarder).
